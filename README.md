# 📚 독서기록장 (Book System)

> **파편화된 개인 독서 기록을 하나로 통합하여 관리할 수 있는 Java Swing 기반 데스크톱 애플리케이션**  
> *2025학년도 인하공업전문대학 컴퓨터정보공학과 특성화 사업 (자바 프로젝트 진행 결과보고서)*

* **개발 기간:** 2025. 11. 04. ~ 2025. 11. 29. (4주)
* **보고서 제출일:** 2025. 12. 15.
* **소속 / 팀명:** 인하공업전문대학 컴퓨터정보공학과 / **팀 독기**
* **개발 분야:** 윈도우 응용프로그램 (Desktop Application)

---

## 📖 1. 프로젝트 개요

### 개발 목적 및 배경
종이 노트나 여러 앱에 흩어져 있는 개인의 독서 기록을 하나의 통합된 시스템으로 효율적으로 관리하기 위해 기획되었습니다. 직관적인 카드형 UI를 통해 책 등록부터 한줄평, 인상 깊은 문장 수집, 목록 조회까지 단일 데스크톱 환경에서 쉽고 빠르게 이용할 수 있도록 구성했습니다.

### 목표 및 기대 효과
* **개인화된 독서 공간:** 회원가입, 로그인 및 보안 문자(CAPTCHA) 인증을 통해 사용자별 독립된 독서 기록 공간을 제공합니다.
* **안정적인 데이터 관리:** MySQL 데이터베이스와 Java JDBC를 연동하여 도서 및 감상 기록의 CRUD(등록, 조회, 수정, 삭제)를 안정적으로 처리합니다.
* **독서 습관 형성:** 복잡한 과정 없이 기록을 한눈에 열람하고 관리할 수 있어 지속적인 독서 기록 습관 형성에 기여합니다.

## ✨ 3. 핵심 기능

### 1) 사용자 인증 (`Login`, `Signup`, `SetPassword`)
* **회원가입 및 로그인:** 이메일, 이름, 비밀번호를 통한 계정 생성 및 로그인 기능을 제공합니다.
* **보안 문자(CAPTCHA):** 로그인 시 자동 입력 방지를 위한 보안 문자 확인 절차를 거칩니다.
* **비밀번호 재설정:** 비밀번호 분실 시 계정 이메일 확인 후 새 비밀번호로 재설정할 수 있습니다.

### 2) 도서 등록 및 목록 조회 (`MainFrame`, `BookAddFrame`)
* **카드 형태 메인 뷰:** 등록된 모든 도서를 메인 화면 중앙에 반응형 카드 레이아웃으로 배치하여 한눈에 볼 수 있습니다.
* **도서 등록 및 삭제:** 책 제목, 저자, 장르(분야) 입력 및 표지 이미지 업로드를 지원하며, 카드 우측 하단 삭제 아이콘으로 간편하게 삭제할 수 있습니다.

### 3) 독서 감상 및 문장 수집 관리 (`BookClick`)
* **상세 기록 관리:** 독서 상태, 날짜, 별점, 한줄평을 작성하고 수정할 수 있습니다.
* **문장 수집 분리 기능:** 한줄평과 별도로 책 속의 인상 깊은 문장과 페이지 번호를 따로 수집·삭제할 수 있도록 세분화했습니다.

## 📘 6. 사용자 설명서 (User Guide)

### 🔹 계정 관리
1. **회원가입:** 로그인 화면 하단 `[회원가입하기]` 클릭 → 이메일, 이름, 비밀번호 입력 후 `[회원가입]` 완료
2. **로그인:** 이메일과 비밀번호 입력 → 화면에 표시된 **보안 문자(CAPTCHA)** 정답 입력 후 로그인
3. **비밀번호 재설정:** 로그인 버튼 상단 `[비밀번호를 잊으셨나요?]` 클릭 → 이메일 및 새 비밀번호 입력 후 변경

### 🔹 도서 및 기록 관리
1. **책 추가:** 메인 화면 우측 상단 `[책+]` 버튼 클릭 → 제목, 분야, 저자 입력 및 표지 이미지 업로드 후 등록
2. **상세 기록 작성:** 메인 화면에서 원하는 책 카드 클릭 → 독서 상태, 날짜, 별점, 한줄평, 문장 수집 입력 후 저장
3. **책 삭제:** 메인 화면 도서 카드 우측 하단의 `[⌫]` 아이콘 클릭

> **⚠️ 사용 시 주의사항**
> * **문장 수집** 기능을 이용할 때는 **페이지 번호를 반드시 입력**해야 정상적으로 저장됩니다.
> * 책 표지 이미지는 **로컬 파일 경로**를 참조하므로, 원본 이미지 파일의 위치를 이동하거나 삭제하면 화면에 표시되지 않을 수 있습니다.
